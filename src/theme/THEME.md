# Iron Workshop HUD Theme

本目录是可运行主题源；已同步为个人 Skill：

`C:\Users\yu\.cursor\skills\iron-workshop-hud\`

| 文件 | 用途 |
|------|------|
| `SKILL.md` | 触发条件、硬约束、移植步骤 |
| `recipes.md` | HTML/组件类名配方 |
| `pack/` | 与本目录对齐的 CSS/JS 包 |

修改主题时：**先改本仓库 `src/theme/`，再复制回 skill `pack/`**，避免分叉。

## 目录

```
theme/
├── tokens.css
├── echarts-theme.js
├── index.css
├── THEME.md
└── components/
```

## Token 前缀

全部 `--iw-*`。主青 `#00e8ff`，辅金 `#e8b84a`，画布 1920×1080。硬约束见 Skill `SKILL.md`。
